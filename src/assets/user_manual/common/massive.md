# Carga masiva

La carga masiva te permite subir información en lote desde un archivo Excel.

## ¿Cómo funciona?
1. Haz clic en Carga masiva.
2. Descarga la plantilla.
3. Llena la hoja con los datos correctos.
4. Sube el archivo.
5. Revisa el resumen final.

## Resumen que muestra el sistema
- Insertados
- Duplicados
- Errores

Si el archivo tiene columnas incorrectas o faltantes, el sistema lo marca para que lo corrijas.

> Se recomienda descargar la plantilla y usarla como base para evitar errores.
