# Navegación general

La plataforma tiene una estructura sencilla.

## Barra lateral
En la izquierda se muestran los módulos disponibles según tu rol.

## Barra superior
En la parte superior derecha puedes:
- Ver usuario actual
  - Abrir tu perfil
  - Cerrar sesión
- Cambiar el tema visual
