# Información personal

Desde el menú superior puedes abrir tu perfil.

## Qué puedes actualizar
- Nombre
- Apellido
- Correo electrónico
- Contraseña

## Importante
Si cambias la contraseña, el sistema cerrará la sesión actual para que vuelvas a iniciar sesión con la nueva clave.
